# HDP LAUNDRY Flutter

Aplikasi Flutter HDP LAUNDRY dengan Firebase Authentication (email/password) dan Cloud Firestore untuk profil pengguna, layanan, serta pesanan realtime.

## Mulai cepat
1. Baca `docs/firebase-setup.md` dan siapkan Firebase Authentication + Firestore Rules.
2. Pastikan `android/app/google-services.json` sesuai project Firebase `hdp-laundry` dan package Android `com.example.aplikasi_hdp_laundry`.
3. Jalankan `flutter pub get`, lalu `flutter run`.

Untuk langkah menyiapkan role Owner/Petugas dan aturan Firestore, lihat `docs/firebase-setup.md`.
